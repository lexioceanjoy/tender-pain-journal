# Milestone 03 — Iteration A review gate

## Goal

Reduce the perceived and actual effort of recording pain without removing Tender's existing detail, privacy, history, or summary capabilities.

## Acceptance criteria

1. Tender opens on a calm Today screen with one clear New check-in action.
2. Today, History, Insights, and More are independently reachable on a phone.
3. A basic entry requires only location and a deliberate intensity choice, with Save before optional context.
4. Repeat Last creates a new entry with current time and pain-specific settings only.
5. Existing body-map precision, per-area settings, context, history editing, insights, backup, and safety remain reachable.
6. Unit, integration, production-build, and phone/desktop browser journeys pass.
7. When optional details carry the primary Save action off-screen, a contextual Save action remains reachable without covering the form or navigation.

## Review gate

This branch remains unpublished until the product owner tries the local phone-sized workflow. The review should focus on check-in speed, whether the body map still feels usable in the focused flow, clarity of Repeat Last, and bottom-navigation reachability.
